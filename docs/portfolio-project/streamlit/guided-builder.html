Where you are in the path

  1. Setup works: the Puppies page says it connected to MySQL.
  2. Demo works: you searched for a puppy’s tricks, added a breed, and saw it in the results.
  3. Your SQL works: you tested one insert, one list query, and one filtered portfolio query in MySQL.
  4. Now: use the form below to create the only part of the starter file you need to personalize.

Checkpoint A — choose an easy first interaction

Pick one table where a person can add a row without needing a complicated series of related records first. A lookup or parent table is often a good first choice. You can still show that your design is connected by making your list query show a readable value from a related table.

Before you continue, have this readyExample of what “ready” means
A one-sentence user action“A coordinator can add an event so members can find it later.”
A tested insertThe insert works in MySQL before it goes into Streamlit.
A tested list queryThe list shows the new row; a join can replace an ID with a readable value.
A tested filtered queryOne %s placeholder receives a value from the app’s text box.

If you do not have these yet, return to Plan Your App. This builder does not invent table or column names.

Checkpoint B — create your project settings

Fill in this form from SQL that already works. Nothing you type here leaves your browser. Select Generate project settings, then copy the result into the starter file.

Checkpoint C — put the settings in the starter

  1. Download project_app_starter.py, place it in your Streamlit folder, and rename it project_app.py.
  2. Open it in VS Code. Near the top, find the area between YOUR PROJECT SETTINGS and Supplied app structure.
  3. Replace only the settings inside that area with the generated settings above. Do not delete the imports or any code below the second divider.
  4. Save the file. Continue to Build Your App for the run-and-test checklist.
Use AI after your plan—not before it. If you ask an AI tool for help, paste your tested SQL and relevant CREATE TABLE statements. Ask it to check your generated settings against those exact identifiers. Do not ask it to design an entire app for you.
