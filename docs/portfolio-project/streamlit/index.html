This is not a Python course. You will use a prepared starter app and explain the database interaction it makes possible. You are not expected to write an app from scratch or become a Streamlit expert.

What you will learn

Your database is useful beyond a SQL editor. A small front end can collect information, request a database action, and show a useful result to a person who never sees the SQL behind it.

What your portfolio app needs to demonstrate

  1. A person enters information and presses a button to add one row to a project table.
  2. The app lists data afterward so the person can confirm the change.
  3. A text box supplies one value for a useful query that filters or searches data.
Keep the scope small. One clear working screen is stronger than an unfinished website. When practical, show a readable related value—not only an ID—so a person can see why your database relationships matter.

Use AI carefully

An AI tool can help you adapt the starter file, but it does not know your schema unless you give it your real table and column names. First make the plan, test the SQL in MySQL, then use the starter. You are directing the tool; it is not guessing your design.
