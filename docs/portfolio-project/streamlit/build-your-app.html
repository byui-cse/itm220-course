Goal

Adapt one prepared Streamlit app so a person can add one row, see data afterward, and run one useful filtered query. You are not starting from an empty Python file.

1. Make your copy

  1. Download project_app_starter.py.
  2. Place it in your Streamlit folder.
  3. Rename the copy project_app.py.
  4. Open it in VS Code.
Only edit the section named “YOUR PROJECT SETTINGS.” The rest supplies the connection, form, buttons, result displays, and error messages.

2. Paste the settings you generated

Complete the Guided Project App Builder first. In project_app.py, replace only the lines between YOUR PROJECT SETTINGS and Supplied app structure with the generated settings. Do not edit the imports or the code below the second divider.

3. Start the app

streamlit run project_app.py

In the Connection panel, enter the MySQL information that works on your computer and the name of your project database.

4. Test it as a user

  1. Enter a clearly identifiable test record in the form.
  2. Select the insert button once.
  3. Confirm that the app reports success.
  4. Show the list and find the new record or a useful related result.
  5. Enter a value in the query text box and select the query button.
  6. Explain what the returned results mean.
Be ready to explain the design connection. During your portfolio video, explain what a person enters, which table receives the row, what the page lists afterward, and why the result is useful. You do not need to explain every line of Python.

If something fails, use Quick Help before rebuilding the app.
