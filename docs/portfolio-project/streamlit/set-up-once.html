Set Up Once

Prepare your computer to run a small Streamlit page that talks to your local MySQL database.

Start HereSet Up OncePuppies WalkthroughPlan Your AppBuild Your AppQuick Help
This is a one-time computer setup. You are not expected to understand Python. Follow the command box for your operating system exactly. When it works, you will use the same short run command for the rest of the course.

What you are setting up

You will create a private project folder with its own Python environment, install two small packages, and run a prepared Puppies web page. The page runs only on your computer and connects only to MySQL on your computer.

You need

  • Your local MySQL server running
  • The current puppies schema loaded
  • Your own MySQL username and password
  • A laptop with VS Code and Python

You do not need

  • Prior Python experience
  • A GitHub account
  • To deploy a public website
  • To put your MySQL password in a code file

1. Get the two free tools

  1. Install or open Visual Studio Code.
  2. Install Python if it is not already installed. Current Streamlit supports Python 3.10–3.14; choose a current Python 3 release.
  3. In VS Code, install the Microsoft Python extension if VS Code asks you to. It helps VS Code recognize the project environment you create below.
Windows installer note: if the Python installer offers an option to add Python to PATH, select it. Then fully close and reopen VS Code after the install.

2. Make one project folder

  1. Create a folder somewhere easy to find, such as Documents/sql_frontend.
  2. Download puppies_frontend_demo.py and place it in that folder.
  3. In VS Code, choose File → Open Folder… and open sql_frontend.
  4. Choose Terminal → New Terminal.

3. Follow one path for your computer

Copy one command at a time into the terminal, press Enter, and wait for it to finish before entering the next command.

Windows 10 or 11

First, check which Python command your computer recognizes:

py --version

The version must be 3.10 through 3.14. If it reports 3.9 or earlier, install a current Python 3 release before continuing. If py is not recognized, try python --version. If that reports a supported version, replace only the first command below with python -m venv .venv.

py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install streamlit mysql-connector-python
.\.venv\Scripts\python.exe -m streamlit run puppies_frontend_demo.py

The last command should open a page in your browser. Leave the terminal running while you use the page.

macOS

First, check that Python is available:

python3 --version

The version must be 3.10 through 3.14. If it reports 3.9 or earlier, install a current Python 3 release before continuing.

Then run:

python3 -m venv .venv
./.venv/bin/python -m pip install --upgrade pip
./.venv/bin/python -m pip install streamlit mysql-connector-python
./.venv/bin/python -m streamlit run puppies_frontend_demo.py

The last command should open a page in your browser. Leave the terminal running while you use the page.

If the package installation reports that Apple command-line developer tools are missing, run xcode-select --install, finish Apple’s installation prompt, reopen VS Code, and repeat the package-install command.

Why these commands look longer than usual: they intentionally use the Python inside this project’s .venv folder. That keeps this project’s packages together, avoids the Windows “scripts are disabled” problem, and prevents Streamlit from being installed into the wrong Python location.

4. Prove the setup worked

  1. In the browser page, open the Connection panel on the left.
  2. Leave the host as 127.0.0.1 and port as 3306, unless your MySQL server uses a different port.
  3. Enter the MySQL username and the password you used when you installed MySQL.
  4. If you do not remember that password, return to the MySQL installation assignments in Canvas and review the password suggested in the course.
  5. Select Test connection.
  6. When you see “Connected to the Puppies database,” continue to the Puppies Front-End Walkthrough.

Your password is typed into a page running on your own computer. It is not saved in the starter file or sent to GitHub.

Next time you open the project

You do not need to install packages again. Open the same folder in VS Code, open a terminal, and use only the final command for your operating system:

WindowsmacOS
.\.venv\Scripts\python.exe -m streamlit run puppies_frontend_demo.py./.venv/bin/python -m streamlit run puppies_frontend_demo.py

To stop the page, return to the terminal and press Ctrl+C. If the browser says the address is already in use, Streamlit is probably still running in another terminal; find that terminal and press Ctrl+C there.

Common first-time issues

What happened?What to do
py, python, or python3 is not recognizedInstall Python from python.org, ensure the Windows PATH option was selected, then close and reopen VS Code.
No module named streamlitUse the full project command above—not just streamlit run. It always uses the right environment.
Connection failedMake sure MySQL is running. Check the port, username, password, and that the database is named puppies.
MySQL is on port 3307Change only the port in the page’s Connection panel to 3307.

Why this guide is different

This guide keeps the spirit of the earlier setup tutorial but uses the current recommended venv and pip approach from Streamlit, a project-local environment that VS Code can discover automatically, and the official MySQL Connector/Python package. The original Streamlit Setup guide remains available as a reference.
