Goal

Interact with the puppies database through a web page. You are not writing Python in this activity. Notice what the database makes possible for a person using the page.

Before you begin

  1. Complete the existing setup guide far enough that Streamlit opens a page in your browser.
  2. Confirm that the puppies database is available in MySQL.
  3. Download puppies_frontend_demo.py into the same folder where you completed your Streamlit setup.

Start the app

streamlit run puppies_frontend_demo.py

Streamlit should open a browser tab. In the Connection panel, enter the MySQL username and the password you used when you installed MySQL. If you do not remember that password, return to the MySQL installation assignments in Canvas and review the password suggested in the course. Leave the host and port at their default values unless your local installation uses a different port. Select Test connection.

Your password is used only to connect to MySQL on your own computer. The starter file does not store it.

Try these three user actions

  1. Find a puppy's tricks. Type part of a puppy name and select Show tricks. The result follows the connections among puppy, puppy_trick, and trick.
  2. Add a breed. Enter a harmless made-up breed name and select Add breed. The app sends an insert action to the database.
  3. Confirm the change. Select Show breeds and find the new breed. The list is the user's confirmation that the action worked.

What just happened?

Input

Text boxes collect information from a person.

Action

Buttons tell the app when to ask MySQL to do something.

Result

A query turns database rows into an understandable answer.

If you would like a second, code-focused example of the insert pattern, the existing Insert with Streamlit tutorial remains available as a reference.

Ready to continue?

Before you move on, you should be able to explain what a person did, what database action occurred, and how the results helped that person. You do not need to explain the Python syntax. Continue to Plan Your App.
