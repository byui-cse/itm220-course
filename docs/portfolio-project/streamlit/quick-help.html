First question

Did the same SQL work in MySQL before you placed it in the app?

  • No: fix and test the SQL in MySQL first.
  • Yes: find the symptom below.
What you seeFirst thing to check
python or streamlit is not recognizedReturn to the existing setup guide and use the Python command that worked on your computer.
No module named streamlitActivate the same virtual environment you used during setup, then install the packages again.
Access denied or cannot connectCheck that MySQL is running, then verify host, port, username, password, and database name. Do not share your password.
Unknown databaseType the exact schema name from MySQL—not the name of one table.
Unknown table or columnCompare spelling against your ERD or CREATE TABLE statement. Do not let an AI tool guess an identifier.
The list does not show the new rowUse a distinctive test value and verify the list query points to the same table.
The filter returns no rowsRun the exact query in MySQL with a known value, then check whether it needs a contains search or an exact value.
Parameter errorFor the filter query, use one %s. For the insert, the number of %s placeholders must match the form fields.

Five words you need

App

The web page a person uses.

Input

A box where a person enters information.

Button

The control that starts an action.

Query

The SQL sent to the database.

Result

The information shown afterward.

Ask for help effectively

Include a screenshot of the error, the terminal command you ran, the relevant SQL, and what you expected to happen. Never include your password.
